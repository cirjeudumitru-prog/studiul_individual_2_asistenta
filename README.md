# Generator de albume foto

Proiect Next.js simplu (App Router). Fotografiile rămân în browser, nu se încarcă nicăieri.

## Rulare
```
npm install
npm run dev
```
Deschide http://localhost:3000

## Structură
- `app/` – layout, pagina principală, stiluri
- `components/` – Header, UploadZone, Controls, PhotoGrid, PhotoCard
- `utils/` – funcții ajutătoare (fișiere, amestecare, mutare)
